# choreographer-dhiraj-website
Premium animated portfolio website for Choreographer Dhiiraj Bhalerao

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm start
   ```

3. Build the project:
   ```bash
   npm run build
   ```

## Tech Stack
* React
* Vite
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide React
